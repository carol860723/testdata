****私人題庫測驗系統 — 使用說明**
本系統提供 題庫匯入、一般測驗、模擬測驗（含打卡）、正式考試與成績單匯出。
以下是最基本的使用方式。**

**1. 匯入題庫**
可上傳 .json 檔或直接貼入 JSON。
步驟：

進入 題庫管理
新增題庫代碼
上傳或貼上題庫 JSON
→ 完成匯入即可開始測驗


**2. 一般測驗（快速練習）**

選擇題庫代碼
選擇題數（10～50 題）
開始作答
完成後立即看解析

用途：日常練習、複習題目。

**3. 模擬測驗（含打卡制度）**

選擇題庫代碼
設定題數與及格分數
開始測驗
完成後自動「打卡」

用途：模擬正式考試、持續練習。

**4. 正式模式（正式考試）**
由管理者預先設定規則：

題數
及格分

流程：

進入正式模式開始測驗
得分 ≥ 及格 → 可下載 PDF 成績單

用途：正式評量、認證、課程通過判定。
